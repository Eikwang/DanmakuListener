# DanmakuListener 开发路线图

## 0. 策略概览
*   **开发策略**: 采用"自底向上"的开发顺序，先完成基础设施层（配置、工具、消息总线），再实现平台适配器，最后封装引擎和主入口。优先完成抖音平台的代理模式，作为 MVP 的核心功能。
*   **MVP 目标**: 实现抖音平台弹幕监听的完整闭环——用户可以通过 `DanmakuListener` 类启动对抖音直播间的监听，实时接收标准化的弹幕数据。

---

## 使用指南

1. **开发顺序**: 严格按照 Phase 编号顺序开发，确保依赖关系正确。
2. **进度更新**: 每完成一个模块，回来勾选对应任务的 `[x]`。
3. **并行开发**: 同一 Phase 内无依赖关系的模块可以并行开发。
4. **测试驱动**: 每个模块完成后立即编写单元测试，确保质量。
5. **文档同步**: 功能完成后同步更新 README 和 API 文档。
