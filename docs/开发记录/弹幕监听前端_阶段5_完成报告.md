## 完成任务

### Task-09: 系统代理控制

**实现文件**：
- `web/bridge.py`（`enable_proxy`、`disable_proxy`、`_get_system_proxy_manager`、`_get_proxy_host`、`_get_proxy_port`）
- `web/app.py`（`api_proxy_enable`、`api_proxy_disable` 路由）

**核心实现**：

1. **`enable_proxy()`**：
   - 调用 `_get_system_proxy_manager()` 获取 SystemProxyManager 实例
   - 调用 `spm.register(host, port)` 设置系统代理
   - 成功返回 `{"success": True, "enabled": True, "host": "127.0.0.1", "port": 8827}`
   - 失败返回 `{"success": False, "error": "Failed to set system proxy, check permissions"}`

2. **`disable_proxy()`**：
   - 调用 `spm.close()` 关闭系统代理
   - 成功返回 `{"success": True, "enabled": False, "host": "", "port": 0}`
   - 失败返回 `{"success": False, "error": "Failed to disable system proxy"}`

3. **辅助方法**：
   - `_get_system_proxy_manager()`: 创建 SystemProxyManager(enabled=True) 实例
   - `_get_proxy_host()`: 从 Settings 读取 proxy_host（默认 "127.0.0.1"）
   - `_get_proxy_port()`: 从 Settings 读取 proxy_port（默认 8827）

4. **API 路由**：
   - `POST /api/proxy/enable` → 调用 `bridge.enable_proxy()`，失败返回 500
   - `POST /api/proxy/disable` → 调用 `bridge.disable_proxy()`，失败返回 500

## 技术决策记录

1. **enable/disable 返回 `enabled` 字段**：`updateProxyUI` 期望 `data.enabled` 字段来设置 toggle 状态。最初 `enable_proxy` 只返回 `{success, host, port}`，缺少 `enabled` 字段导致前端无法正确更新 UI。修复为在成功响应中包含 `enabled: True/False`。

2. **每次创建新 SystemProxyManager 实例**：`_get_system_proxy_manager()` 每次返回新实例而非缓存。因为代理控制是低频操作，且 SystemProxyManager 是无状态的（仅操作注册表），无需缓存。

3. **Playwright 路由拦截**：验证标准 6/7/8 使用 `page.route()` 拦截 API 请求返回 mock 响应，避免真实修改 Windows 注册表。这比启动独立 mock 服务器更轻量。

4. **Toggle 点击方式**：CSS 中 checkbox 是隐藏的（opacity:0），使用 `.slider` span 作为视觉开关。Playwright 需要点击 `#proxy-toggle + .slider` 而非 checkbox 本身。
