## 完成任务

### Task-05: 房间管理 API

**实现文件**：
- `web/app.py`（房间管理路由：GET/POST /api/rooms, DELETE /api/rooms/{platform}/{room_id}, POST /api/rooms/stop-all）
- `web/bridge.py`（add_room, remove_room, stop_all 方法实现）

**核心实现**：

1. **房间添加**（`add_room`）：
   - 调用 `parse_room_spec` 校验格式 → 格式错误抛 RoomError(400)
   - 检查 `_rooms` 字典防重复 → 重复抛 RoomError(409)
   - 调用 `listener.start([room_spec])` 启动监听
   - 捕获 `ProxyStartError` → RoomError(500)
   - 记录房间状态到 `_rooms` 字典

2. **房间移除**（`remove_room`）：
   - 检查房间存在 → 不存在抛 RoomError(404)
   - 从 `_rooms` 中移除
   - 调用 `listener.stop()` 停止监听

3. **全部停止**（`stop_all`）：
   - 清空 `_rooms` 字典
   - 调用 `listener.stop()`（会恢复系统代理）

4. **RoomError 异常类**：
   - 携带 HTTP 状态码，API 层统一捕获转换为 JSON 响应

**新增测试**：14 个（`tests/unit/test_web_rooms_api.py`）

**AC 覆盖**：AC-002, AC-003, AC-006, AC-008, AC-009, AC-013, AC-017

### Task-06: 房间管理 UI

**实现文件**：
- `web/static/app.js`（DanmakuApp 完整实现：房间列表渲染、添加/删除/全部停止交互）
- `web/static/style.css`（room-item、platform-tag、status-badge 样式）

**核心实现**：

1. **房间列表渲染**（`renderRoomList`）：
   - 每个房间显示平台标签、房间 ID、状态徽章（运行中/已停止）、停止按钮
   - 空列表时禁用"全部停止"按钮

2. **添加房间**（`handleAddRoom`）：
   - POST /api/rooms，请求期间按钮置灰防重复提交
   - 409 → 显示"该房间已存在"
   - 其他错误 → 显示服务端错误信息
   - 成功后清空输入框并刷新列表

3. **输入校验**（`validateRoomInput`）：
   - 失焦时检查格式，缺少冒号显示"格式不正确，应为 platform:room_id"

4. **停止单个房间**（`handleRemoveRoom`）：
   - DELETE /api/rooms/{platform}/{roomId}，成功后刷新列表

5. **全部停止**（`handleStopAll`）：
   - POST /api/rooms/stop-all，请求期间按钮置灰，成功后刷新列表和代理状态

## 技术决策记录

1. **RoomError 异常类**：API 层统一异常处理模式。DanmakuBridge 抛出 RoomError（携带 HTTP 状态码），app.py 路由函数捕获后转换为对应状态码的 JSON 响应。避免在每个路由函数中重复错误处理逻辑。

2. **remove_room 行为**：停止房间时直接从 `_rooms` 字典中移除，而非将状态改为"已停止"。因为 DanmakuListener.stop() 会停止整个引擎，房间不再存在。前端列表中该条目消失，符合用户预期。

3. **前端按钮置灰**：`handleAddRoom` 和 `handleStopAll` 在请求期间禁用按钮，使用 `finally` 块确保按钮始终恢复。mock 响应很快无法直接观察，通过 Playwright 读取 JS 源码验证逻辑存在。

4. **前端错误提示**：`handleAddRoom` 对 409 状态码特殊处理为"该房间已存在"（中文友好提示），其他错误使用服务端返回的 error 字段。

5. **Mock 服务器共享状态**：Playwright 验收测试中多个测试共享同一个 mock 服务器实例，通过 `cleanup_rooms()` 在每个测试前调用 stop-all API 清理状态。
